# Weekly Report

Generate a factual project weekly report from supplied source material.

1. Summarize outcomes completed during the reporting period.
2. List next-period priorities with owners and dates when provided.
3. Highlight risks, blockers, decisions, and requested support.
4. Preserve source metrics and avoid inventing progress.
5. Keep the report concise and suitable for stakeholders.
