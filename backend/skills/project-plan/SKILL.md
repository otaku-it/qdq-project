# Project Plan

Create an executable project plan from the user's confirmed objective and constraints.

1. Clarify scope, deadline, team, and constraints.
2. Define measurable milestones and deliverables.
3. Assign owners only when the user provides them.
4. Identify dependencies, risks, and acceptance criteria.
5. Return the plan in execution order.
