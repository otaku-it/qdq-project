# Requirement Analysis

Structure the supplied requirement without inventing business facts.

1. Identify actors, goals, triggers, and expected outcomes.
2. Separate functional and non-functional requirements.
3. Write testable acceptance criteria.
4. Record assumptions, dependencies, risks, and open questions.
5. Highlight conflicts that require a product decision.
